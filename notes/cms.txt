- updatePage(pageId, updates): admin edit content & metadata

ROUTES:
GET    /api/v1/pages/:slug                  - get page by slug (public)
GET    /api/v1/pages                        - list all pages (requires cms:manage)
POST   /api/v1/pages                        - create page (requires cms:manage)
PUT    /api/v1/pages/:id                    - update page (requires cms:manage)
DELETE /api/v1/pages/:id                    - delete page (requires cms:manage)
PUT    /api/v1/pages/:id/publish            - toggle published status (requires cms:manage)

DEFAULT PAGES (seeded):
- about: Company information & mission
- services: Service offerings & features
- contact: Contact details & support info
- privacy: Privacy policy
- terms: Terms of service

PAGE SCHEMA:
- slug: URL-friendly unique identifier (lowercase, hyphen-separated)
- title: Page heading/title
- content: Rich HTML content (supports formatting, images, links)
- metaDescription: SEO meta description (search engines)
- metaKeywords: SEO keywords (comma-separated)
- published: boolean (draft=false, live=true)
- updatedBy: admin user who last edited
- timestamps: createdAt, updatedAt

WORKFLOW:
1. Admin creates page → status: draft (not visible to public)
2. Admin edits content & metadata
3. Admin publishes → status: published (visible at /pages/{slug})
4. Public can only view published pages by slug
5. Admin can unpublish to take page offline

PERMISSIONS:
- Public (no auth): GET /pages/:slug (published only)
- Admin (cms:manage): full CRUD + publish/unpublish
- Other roles: no access

SEO OPTIMIZATION:
